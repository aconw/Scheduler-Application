# Start Here — v2.8.3

Replace the current GitHub application files with this folder and commit to `main`.

## v2.8.3 change
The Job Change report's `Last Separation Date` is supported. For Job Change events:
- blank separation date: historical/equivalent completion remains a valid exemption;
- completion after separation: valid exemption;
- completion on or before separation: not an exemption; normal scheduling continues.

New Hire behavior is unchanged.
